## 📥 Installation

### For New Sites

1. Download `nexus-3.1.1.zip` from the repository
2. Go to WordPress Admin → Appearance → Themes
3. Click "Add New" → "Upload Theme"
4. Choose `nexus-3.1.1.zip`
5. Click "Install Now"
6. Activate the theme
7. Go to Dashboard → Nexus → License
8. Enter your license key: `NEXUS-7D7Y-7BWB-TV8G-9GZQ` (Agency)
9. Click "Activate License"

### For Existing Sites (Update)

#### Option 1: Via FileZilla (Quick Update)
Upload these 3 files only:
- `/wp-content/themes/nexus-theme/pro/templates/class-template-library.php`
- `/wp-content/themes/nexus-theme/pro/assets/js/templates.js`
- `/wp-content/themes/nexus-theme/pro/assets/css/templates.css`

#### Option 2: Full Theme Update
1. Deactivate current Nexus theme (switch to a default theme temporarily)
2. Delete old Nexus theme
3. Upload `nexus-3.1.1.zip` via Themes → Add New → Upload
4. Activate Nexus theme
5. Your license and settings will be preserved

#### Option 3: Via Git (For Developers)
```bash
cd /path/to/wp-content/themes/nexus-theme
git pull origin main
```

## 🧪 Verify Installation

1. Go to Dashboard → Nexus → Templates
2. You should see 50+ templates with colorful gradient placeholders
3. Click "Import" on any template
4. It should create a draft page and redirect to the editor

## 🐛 Troubleshooting

### Templates Not Showing?
- Clear WordPress cache (if using a caching plugin)
- Clear browser cache (Ctrl+Shift+R or Cmd+Shift+R)
- Check that license is activated (Agency tier)

### Import Not Working?
- Check WordPress permissions (PHP write permissions)
- Check PHP error log for details
- Ensure you're logged in as admin
