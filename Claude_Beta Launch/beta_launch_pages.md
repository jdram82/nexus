## 📋 PROCEDURES/WORKFLOWS

### Procedure 1: **New Founders Application Workflow**
```
1. User fills form → Database entry created
2. Auto-notification to admin team
3. Admin reviews (< 24 hours)
4. IF APPROVED:
   → Send approval email
   → Generate license key
   → Add to Founders Slack
   → Create progress tracker
   → Update counter (-1 spot)
5. IF REJECTED:
   → Send rejection email (kind + reason)
   → Offer Early Adopter discount code
```

---

### Procedure 2: **Trial to Paid Conversion Workflow**
```
Day 0: Trial starts
Day 3: Check-in email
Day 10: Feature spotlight
Day 20: Payment reminder
Day 25: Final reminder
Day 30: Charge card OR cancel
  → IF SUCCESS: Welcome email, activate license
  → IF FAIL: Retry 3x over 7 days
  → IF STILL FAIL: Suspend, urgent email
```

---

### Procedure 3: **Founders Requirements Tracking**
```
Installation Date = Day 0
Deadline = Day 60

Weekly Check (Day 7, 14, 21...):
  → Count completed requirements
  → IF < 2 at Day 30: Send reminder
  → IF < 3 at Day 45: Send urgent reminder
  → IF < 4 at Day 55: Final warning

Day 60:
  → IF all 4 complete: Permanent free license
  → IF incomplete: Move to Early Adopter tier
```

---

### Procedure 4: **Bug Report Processing**
```
1. Bug submitted via form
2. Auto-notification to dev team
3. Developer reviews & assigns severity
4. Add to sprint backlog
5. When fixed:
   → Update bug status
   → Notify submitter
   → IF Founders: Count toward requirement
```

---

### Procedure 5: **Payment Failed Recovery**
```
1. Payment fails
2. Immediate email: "Update payment method"
3. Retry after 3 days
4. IF FAIL: Retry after 3 more days
5. IF STILL FAIL: 
   → Suspend license
   → Send urgent email
   → Phone call if high-value customer
6. After 14 days: Cancel subscription
```
