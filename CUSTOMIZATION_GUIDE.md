## 📸 Add Theme Thumbnail/Screenshot

WordPress displays theme screenshots as 1200x900px images. You need to add a file named `screenshot.png` to your theme folder.

### Option 1: Via WordPress Media (Easiest)
1. Create/find an image that represents your theme (1200x900px recommended)
2. Use FTP or File Manager in EasyWP
3. Upload the image to: `/wp-content/themes/nexus-theme/screenshot.png`

### Option 2: Quick Placeholder
For now, you can use a solid color placeholder:
- Download any 1200x900px image
- Name it `screenshot.png`
- Upload to the theme root directory

**After uploading, refresh the Themes page to see the thumbnail!**

## 🎨 Customization Options

### 1. **WordPress Customizer** (Immediate Visual Changes)

Click **"Customize"** button (you saw it!) to access:

#### Colors
- Primary Color
- Secondary Color  
- Text Color
- Link Color
- Background Color

#### Typography
- Heading Fonts
- Body Fonts
- Font Sizes

#### Layout Options
- Site Width
- Sidebar Position
- Header Layout
- Footer Layout

#### Site Identity
- Site Title & Tagline
- Logo Upload
- Site Icon (Favicon)

**To Access:**
- **Appearance** → **Customize**
- Or click the **"Customize"** button on the theme

---

### 2. **Navigation Menus**

Create and manage menus:

1. Go to **Appearance** → **Menus**
2. Create a new menu:
   - **Primary Menu** (main navigation)
   - **Footer Menu** (footer links)
3. Add pages, posts, custom links
4. Assign to menu locations

---

### 3. **Widgets**

Add content to sidebar and footer:

1. Go to **Appearance** → **Widgets**
2. Available widget areas:
   - Sidebar
   - Footer (multiple columns)
3. Drag widgets to activate them

**Click "Widgets" button** you saw to access this.

---

### 4. **Homepage Setup**

Set your homepage:

1. Go to **Settings** → **Reading**
2. Choose:
   - **Latest Posts** (blog homepage)
   - **Static Page** (custom homepage)
3. Select pages for Homepage and Posts page

---

### 5. **Custom Post Types** (Built-in Features)

Nexus includes powerful custom content types:

#### 📦 Products
- **Location:** Dashboard → Products → Add New
- **Use for:** Product showcases, services, software tools
- **Features:** Featured images, descriptions, custom fields

#### 🚀 Projects  
- **Location:** Dashboard → Projects → Add New
- **Use for:** Portfolio items, case studies, client work
- **Features:** Project details, galleries, client info

#### 📥 Downloads
- **Location:** Dashboard → Downloads → Add New  
- **Use for:** Software, documents, resources, files
- **Features:** Version control, download tracking, file management

---

### 6. **WooCommerce Integration** (If Installed)

If you have WooCommerce active:
- Nexus automatically integrates
- Enhanced product layouts
- Custom shop styling

## 📸 Creating a Custom Screenshot

### Recommended Dimensions:
- **Size:** 1200 x 900 pixels
- **Format:** PNG (screenshot.png)
- **Location:** `/wp-content/themes/nexus-theme/screenshot.png`

### What to Include:
- Your site header/logo
- Navigation menu
- Hero section or main content area
- Shows off your design/colors
- Clean, professional look

### Quick Tools:
- **Canva** (free, online)
- **Photoshop/Figma** (professional)
- **Take a screenshot** of your actual site (after customization)

### Steps:
1. Design or screenshot your homepage
2. Resize to 1200x900px
3. Save as PNG
4. Name it `screenshot.png`
5. Upload to theme root via FTP/File Manager

## 🔧 Troubleshooting

### Theme Looks Plain?
- Upload a logo (**Customize** → **Site Identity**)
- Set colors (**Customize** → **Colors**)
- Create a menu (**Appearance** → **Menus**)

### No Sidebar?
- Add widgets (**Appearance** → **Widgets**)
- Check page template (should use default, not full-width)

### Pro Features Missing?
- Pro features are disabled by default on EasyWP
- Core features work perfectly without Pro
- See EASYWP_FIX.md to enable Pro features
