Complete management system for UL-NEC Compliance AutoCAD Plugin with Supabase backend.

== Description ==

UL-NEC Compliance AutoCAD Plugin Manager is a complete SaaS management system for your AutoCAD plugin. It handles:

* User registration and authentication
* License key generation and validation
* Secure file downloads with expiring URLs
* Payment processing (PayPal & Razorpay)
* Bug reporting and feature requests
* Download analytics and tracking

Powered by Supabase for a scalable, secure backend.

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/ul-nec-compliance/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to UL-NEC → Settings and configure your Supabase credentials
4. Upload your .msi file to Supabase Storage
5. You're ready to go!

== Frequently Asked Questions ==

= What is Supabase? =

Supabase is an open-source Firebase alternative providing PostgreSQL database, authentication, storage, and real-time subscriptions.

= Do I need a Supabase account? =

Yes, you need a Supabase account (free or paid) to use this plugin.

= What payment gateways are supported? =

Currently PayPal and Razorpay are supported.
