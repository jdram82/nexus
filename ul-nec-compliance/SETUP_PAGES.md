# WordPress Pages Setup Guide

## Required Pages to Create

After installing the plugin, you need to create these pages in WordPress:

### 1. Bug Report
- **Page Title**: Bug Report
- **Permalink**: `/bug-report/`
- **Content**: `[ulnec_bug_report]`

### 2. Feature Request
- **Page Title**: Feature Request
- **Permalink**: `/feature-request/`
- **Content**: `[ulnec_feature_request]`

### 3. Founders Progress
- **Page Title**: Founders Progress
- **Permalink**: `/founders-progress/`
- **Content**: `[ulnec_founders_progress]`

### 4. Account Settings
- **Page Title**: Account Settings
- **Permalink**: `/account-settings/`
- **Content**: `[ulnec_account_settings]`

### 5. Billing
- **Page Title**: Billing
- **Permalink**: `/billing/`
- **Content**: `[ulnec_billing]`

## Quick Setup Steps

1. Go to WordPress Admin → **Pages** → **Add New**
2. Enter the page title
3. Add the shortcode in the content area (Gutenberg: use Shortcode block)
4. Click **Publish**
5. Repeat for all 5 pages

## Troubleshooting

**"Nothing Found" Error**: This means the page doesn't exist yet in WordPress. Create the page first, then add the shortcode.

**Dark Background Not Showing**: Clear your browser cache and WordPress cache after updating the plugin.
