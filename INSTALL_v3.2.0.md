## 🚀 Installation Methods

### Method 1: Automatic Update (Recommended)

If you're running v3.1.9 or earlier:

1. Go to **Dashboard** → **Updates**
2. Find **Nexus Theme v3.2.0** in the list
3. Click **Update Now**
4. Wait for completion (automatic)

### Method 2: Manual Upload

1. Download `nexus-3.2.0.zip` from the distribution folder
2. Go to **Appearance** → **Themes**
3. Click **Add New** → **Upload Theme**
4. Choose `nexus-3.2.0.zip`
5. Click **Install Now**
6. If updating: Click **Replace current with uploaded**
7. Activate the theme

### Method 3: FTP Upload

1. Extract `nexus-3.2.0.zip` to your computer
2. Connect to your server via FTP/SFTP
3. Navigate to `/wp-content/themes/`
4. Delete existing `nexus` folder (backup first!)
5. Upload extracted `nexus` folder
6. Go to **Appearance** → **Themes** and activate

## 🛠️ Troubleshooting

### Issue: Update doesn't appear in WordPress

**Solution:**
1. Clear WordPress transients
2. Go to **Appearance** → **Nexus Updates**
3. Click **Check for Updates Now**

### Issue: PHP warnings still appear

**Solution:**
1. Clear all caches (WordPress, server, browser)
2. Verify version is actually v3.2.0 (**Appearance** → **Themes**)
3. Check file permissions on `/pro/popup-builder/views/`

### Issue: Templates page blank

**Solution:**
1. Verify Advanced or Agency license is active
2. Check browser console for JavaScript errors
3. Clear browser cache and reload
