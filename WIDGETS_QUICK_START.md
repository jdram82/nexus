# Phase 4 Widgets - Quick Start Guide

**Version:** 3.2.1  
**Status:** Production Ready ✅  
**Widgets Available:** 5

## 🚀 Quick Access

### Where to Find These Widgets

1. Go to **Nexus Dashboard** → **Theme Builder**
2. Click **"Content"** category in widget panel
3. Look for these 5 new widgets:
   - ⭐ **Star Rating**
   - 🖼️ **Gallery**
   - 📋 **Icon List**
   - 🔽 **Toggle**
   - 🔗 **Social Icons**

---

## ⭐ Star Rating Widget

### Quick Setup
1. Drag **Star Rating** to canvas
2. Set rating value (0-5)
3. Customize colors
4. Choose alignment
5. Done!

### Common Settings
- **Rating:** 4.5 / 5
- **Star Color:** Gold (#FFD700)
- **Size:** 24px
- **Alignment:** Center

### Example Use
Perfect for:
- Product reviews (Amazon-style)
- Service ratings
- Testimonial scores
- Skill level indicators

---

## 🖼️ Gallery Widget

### Quick Setup
1. Drag **Gallery** to canvas
2. Click **"Add Images"**
3. Select multiple images
4. Choose columns (3 recommended)
5. Pick hover effect (zoom is nice!)

### Popular Layouts
- **Grid 3 columns** - Standard portfolio
- **Masonry 4 columns** - Pinterest style
- **Justified** - Google Photos style

### Pro Tip
Use **Zoom hover effect** + **Show captions** for interactive galleries.

---

## 📋 Icon List Widget

### Quick Setup
1. Drag **Icon List** to canvas
2. Click **"Add Item"**
3. Choose icon from Dashicons
4. Add text
5. Repeat for more items

### Common Uses
**Features List:**
- ✅ Fast Performance (icon: yes-alt)
- ✅ Mobile Responsive (icon: smartphone)
- ✅ SEO Optimized (icon: chart-line)

**Contact Info:**
- 📧 email@example.com (icon: email)
- 📱 (555) 123-4567 (icon: phone)
- 📍 123 Main St (icon: location)

### Layout Options
- **Vertical** - Traditional list
- **Horizontal** - Feature highlights

## 📱 Responsive Behavior

All widgets are **mobile-optimized** automatically:

- **Gallery:** 6 columns → 2 columns on mobile
- **Icon List:** Horizontal → Vertical on mobile
- **Social Icons:** Wraps automatically
- **Toggle:** Full-width, touch-friendly
- **Star Rating:** Scales proportionally

---

## ⚡ Performance Tips

1. **Gallery Widget:**
   - Use WordPress image sizes (medium/large)
   - Don't upload images > 2MB
   - Limit to 50 images per gallery

2. **Icon List:**
   - Keep to 10-15 items max
   - Use simple icon styles

3. **Toggle Widget:**
   - Limit content per section
   - Don't nest toggles

4. **Social Icons:**
   - Show only active networks
   - 6-8 icons maximum

## 🔧 Troubleshooting

### Widget Not Showing?
1. Check **License Tier** (Advanced/Agency required)
2. Clear WordPress cache
3. Refresh Theme Builder

### Stars Not Aligned?
- Check parent container width
- Set alignment in widget settings
- Clear browser cache

### Gallery Images Not Loading?
- Verify image size exists
- Check media library uploads
- Test with different image size

### Icons Not Displaying?
- Ensure Dashicons are loaded
- Check icon color (might blend with background)
- Try different icon

### Toggles Not Opening?
- Check for JavaScript errors (F12)
- Ensure jQuery is loaded
- Try different browser

## 🎓 Best Practices

### Star Rating
✅ Use consistent max rating (usually 5)  
✅ Show decimal values (4.7 vs 5)  
✅ Add descriptive title  
❌ Don't make stars too small (min 16px)  

### Gallery
✅ Use consistent image ratios  
✅ Optimize images before upload  
✅ Enable hover effects for engagement  
❌ Don't mix portrait and landscape in grid  

### Icon List
✅ Keep text concise  
✅ Use relevant icons  
✅ Maintain visual hierarchy  
❌ Don't use too many different icon colors  

### Toggle
✅ Use descriptive titles  
✅ Keep content scannable  
✅ Order by importance  
❌ Don't nest content too deep  

### Social Icons
✅ Link to actual profiles  
✅ Use brand colors option  
✅ Keep icon count reasonable  
❌ Don't include inactive networks
