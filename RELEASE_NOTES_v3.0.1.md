## 🔧 Installation

### For New Installations:
1. Download `nexus-v3.0.1.zip`
2. Upload to WordPress: Appearance → Themes → Add New → Upload Theme
3. Activate the theme

### For Existing Nexus Users:
1. Deactivate current Nexus theme (if active)
2. Delete old version
3. Upload v3.0.1
4. Reactivate theme
5. **Your license will remain active** - no need to reactivate

## 📋 License Activation

### Activate Your License:
1. Go to: **Dashboard → Nexus → License**
2. Enter your license key: `NEXUS-XXXX-XXXX-XXXX-XXXX`
3. Click: **Activate License**
