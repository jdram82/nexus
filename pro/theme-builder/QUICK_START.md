# Nexus Theme Builder - Quick Start Guide

**Get started with the Theme Builder in 5 minutes!**

---

## 🚀 Quick Start

### Step 1: Verify Your License

The Theme Builder is available for **Advanced** and **Agency** tier users only.

1. Go to **Nexus Options → License**
2. Verify your tier shows "Advanced" or "Agency"
3. If you see "Pro" or "Free", you'll need to upgrade

---

### Step 2: Access the Builder

**Option A: From Nexus Menu**
1. Go to **WordPress Admin → Nexus Options → Theme Builder**
2. Click the **"Launch Builder"** button

**Option B: Enable on a Post/Page**
1. Edit any post or page
2. Look for the **"Nexus Builder"** meta box in the sidebar
3. Check ✅ **"Enable Nexus Builder for this page"**
4. Click **"Edit with Builder"** button

---

### Step 3: Build Your First Page

#### Add Your First Section
1. You'll see a large canvas area with "Drag widgets here to start building"
2. The left panel shows all available widgets organized by category

#### Add Widgets
1. **Drag** any widget from the left panel
2. **Drop** it onto the canvas
3. Watch it appear instantly!

**Try these widgets first:**
- **Heading** (Basic category)
- **Button** (Basic category)
- **Image** (Basic category)

#### Edit Widget Settings
1. **Click** on any widget in the canvas
2. The **right panel** opens with settings
3. Change text, colors, alignment, etc.
4. See changes **live** in the canvas!

---

### Step 4: Save Your Work

**Method 1: Save Button**
- Click the blue **"Save"** button in the top-right corner

**Method 2: Keyboard Shortcut**
- Press **Ctrl+S** (Windows) or **Cmd+S** (Mac)

You'll see a success message when saved! ✅

## 🎨 Essential Features

### Device Preview
Test your design on different screens:

1. Look at the **device switcher** in the top center
2. Click icons to preview:
   - 🖥️ **Desktop** (default)
   - 📱 **Tablet**
   - 📱 **Mobile**

The canvas resizes to show exactly how your page looks on each device!

### Undo/Redo
Made a mistake? No problem!

- **Undo:** Click undo button or press **Ctrl+Z**
- **Redo:** Click redo button or press **Ctrl+Shift+Z**

The builder remembers your last 50 changes!

### Widget Controls
When you hover over a widget, you'll see 3 buttons:

- ✏️ **Edit** - Open settings panel
- 📋 **Duplicate** - Create a copy
- 🗑️ **Delete** - Remove widget

## 📚 Using Templates

### Load a Template
Want a head start? Use a pre-built template:

1. Click **"Templates"** button in the top-right
2. Browse available templates
3. Click **"Load"** on any template
4. Confirm to apply it to your page

**Available Templates:**
- Tech Homepage
- Product Showcase
- Corporate Homepage
- About Company
- Contact Page
- And more!

### Save Your Own Template
Created something amazing? Save it for later:

1. Click **"Templates"** button
2. Switch to **"Save Template"** tab
3. Enter a name for your template
4. Click **"Save Template"**

Now you can reuse this design on other pages!

## 🎯 Popular Widgets Guide

### Heading Widget
Perfect for titles and section headers
- Choose heading tag (H1-H6)
- Change color, size, alignment
- Add optional link

### Button Widget
Call-to-action buttons
- Customize text and link
- Choose style (Primary, Secondary, Outline)
- Select size (Small, Medium, Large)
- Pick colors

### Image Widget
Add images with captions
- Upload from media library
- Choose image size
- Add optional link
- Include caption text

- Add title and description
- Customize colors

### Accordion Widget
Collapsible content sections

- Customize colors

## ⚡ Pro Tips

### 1. Use Keyboard Shortcuts
- **Ctrl+S** - Save
- **Ctrl+Z** - Undo
- **Ctrl+Shift+Z** - Redo
- **Delete** - Remove selected widget

### 2. Search for Widgets
Can't find a widget?
- Use the **search box** at the top of the widgets panel
- Type widget name (e.g., "button", "image")
- Results filter instantly

### 3. Widget Organization
Widgets are organized into categories:
- **Basic** - Essential elements (heading, text, button, image)
- **Content** - Advanced content (icon box, counter, accordion)
- **Forms** - Form elements
- **WordPress** - WP-specific (posts, products, menu)
- **Pro** - Technical widgets (code block, datasheet, specs)

### 4. Global Styles
Set site-wide colors and fonts:
1. Click **"Global Styles"** button
2. Choose primary/secondary colors
3. Select heading and body fonts
4. Save to apply across all pages

### 5. Responsive Design
Always check your design on all devices:
- Design on **desktop** first
- Check **tablet** view
- Verify **mobile** appearance
- Adjust as needed

## 🐛 Troubleshooting

### Builder Won't Load
**Solution:**
1. Clear browser cache
2. Disable browser extensions
3. Check JavaScript console for errors
4. Verify license is active

### Widgets Won't Drag
**Solution:**
1. Ensure you're dragging from the widget icon/name
2. Try refreshing the page
3. Check that jQuery UI is loaded

### Changes Not Saving
**Solution:**
1. Check your internet connection
2. Verify you have permission to edit the page
3. Look for error messages in the console
4. Try manual save with "Save" button

### Template Won't Load
**Solution:**
1. Ensure template file exists
2. Check file permissions
3. Verify JSON syntax is valid
