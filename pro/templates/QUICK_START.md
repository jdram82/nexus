# Template Manager Quick Start Guide

## 🚀 Getting Started in 5 Minutes

### Prerequisites

- ✅ Nexus Theme installed and activated
- ✅ Advanced or Agency tier license activated
- ✅ WordPress 5.8 or higher
- ✅ PHP 7.4 or higher

## Step 1: Access Template Library

1. Log into WordPress admin
2. Navigate to **Pro Features > Template Library**
3. You'll see tabs for:
   - **Browse** - View all templates
   - **Export** - Export your pages as templates
   - **Cloud Sync** - Manage cloud templates (Pro+)

## Step 2: Browse Templates

### Using Category Filters

Click on any category to filter templates:

- 🏢 **Business** - Corporate and professional sites
- ☁️ **SaaS** - Software and cloud services
- 🛒 **E-commerce** - Online stores
- 🎨 **Portfolio** - Creative showcases
- 📝 **Blog** - Content and magazine layouts
- 📚 **Documentation** - Docs and knowledge bases
- 🚀 **Landing Page** - High-converting pages
- 📊 **Marketing** - Agency and marketing sites
- 🎓 **Education** - Courses and learning
- 🎫 **Events** - Conferences and meetups

### Using Search

Type keywords in the search bar:
- "homepage" - Find all homepage templates
- "minimal" - Find minimal design templates
- "photography" - Find photography portfolios
- "api" - Find API documentation templates

### Using Type Filter

Filter by template type:
- **Page** - Full page templates
- **Landing** - Landing page templates
- **All** - Show all types

## Step 3: Import a Template

### Quick Import (Recommended)

1. Find a template you like
2. Click the **Import** button on the template card
3. Confirm the import dialog
4. Wait 5-10 seconds for import to complete
5. You'll be redirected to edit your new page

### Preview First

1. Click the **Preview** button on any template
2. Review the design and content
3. Choose import options:
   - ✅ **Import Settings** - Theme colors, fonts, etc.
   - ✅ **Import Content** - Page content and structure
   - ✅ **Import Media** - Download images
4. Click **Import Template** in the modal
5. Edit your new page

## Step 4: Customize Your Page

After import:

1. **Edit Content**: Update text, images, and links
2. **Customize Design**: Go to Appearance > Customize
3. **Publish**: Click "Publish" when ready
4. **View Live**: Click "View Page" to see your site

## Export Your Own Templates

### Export a Page

1. Design your page in WordPress
2. Go to **Pro Features > Template Library**
3. Click the **Export** tab
4. Select your page from dropdown
5. Click **Export Template**
6. JSON file downloads to your computer
7. Share or reuse the template

### Reuse Exported Template

**Option 1: Import on Same Site**
1. Upload JSON file to `/pro/templates/data/`
2. Refresh Template Library page
3. Your template appears in the grid

**Option 2: Import on Another Site**
1. Install Nexus theme on new site
2. Activate Advanced/Agency license
3. Upload JSON file to `/pro/templates/data/`
4. Import like any other template

**Option 3: Share with Team**
1. Send JSON file to team members
2. They add it to their `/pro/templates/data/` folder
3. Template available for their use

## Cloud Sync (Pro+)

### Automatic Sync

Templates automatically sync to cloud when:
- You import a template (within tier limits)
- You create a template from export

### Tier Limits

- **Pro Tier**: 5 templates
- **Advanced Tier**: Unlimited templates
- **Agency Tier**: Unlimited templates

### Manual Sync

1. Go to **Cloud Sync** tab
2. Click **Sync Now** button
3. Wait for sync to complete
4. Synced templates show "Cloud" badge

### Access from Another Site

1. Install Nexus on new site
2. Activate same license
3. Go to Template Library
4. Templates with "Cloud Synced" badge are available
5. Click **Import** to use them

## Tips & Tricks

### 💡 Faster Workflow

1. **Use Keyboard Shortcuts**: Press ESC to close preview modal
2. **Batch Import**: Import multiple templates at once
3. **Save Favorites**: Star favorite templates (coming soon)
4. **Quick Edit**: Edit immediately after import

### 🎨 Design Consistency

1. **Import Settings**: Always enable for consistent branding
2. **Color Scheme**: Set once, applies to all imports

1. **Skip Media**: Disable media import for faster testing
2. **Local Images**: Replace remote images with local files
3. **Lazy Load**: Enable lazy loading for images
4. **Optimize**: Use image optimization plugins

### 📱 Mobile Testing

1. **Preview Responsive**: Check mobile view in preview
2. **Test on Device**: View on actual mobile devices
3. **Adjust Spacing**: Fix mobile padding if needed
4. **Touch Targets**: Ensure buttons are 44x44px minimum

## Troubleshooting

### Template Won't Import

**Problem**: Import button does nothing

**Solution**:
1. Check browser console for errors
2. Verify Advanced/Agency tier is active
3. Try refreshing the page
4. Clear browser cache

### Images Not Loading

**Problem**: Imported page has broken images

**Solution**:
1. Enable "Import Media" option
2. Check internet connection
3. Verify image URLs are accessible
4. Re-import with media enabled

### Page Looks Different

**Problem**: Imported page doesn't match preview

**Solution**:
1. Enable "Import Settings" option
2. Check active plugins don't conflict
3. Clear cache (site and browser)
4. Re-import with all options enabled

### Can't Find Template

**Problem**: Template not showing in grid

**Solution**:
1. Check category filter is set to "All"
2. Clear search field
3. Verify JSON file exists in `/pro/templates/data/`
4. Refresh page
