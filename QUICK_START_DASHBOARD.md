# 🚀 Quick Start - Nexus Admin Dashboard v3.1.0

## ⚡ 60-Second Setup

### 1. Upload Theme
- Go to your WordPress admin
- Navigate to **Appearance > Themes > Add New > Upload Theme**
- Select `nexus-theme-v3.1.0.zip`
- Click **Install Now** then **Activate**

### 2. Access Dashboard
- Look for **Nexus** menu in WordPress admin sidebar (left side)
- Click **Nexus > Dashboard**
- You're in! 🎉

### 3. Explore Features
- **Dashboard:** Overview and stats
- **Templates:** Browse 8 starter templates
- **Settings:** Configure theme options
- **Getting Started:** Onboarding guide

## 🆘 Troubleshooting

### "Nexus menu not showing"
**Fix:**
1. Verify theme is activated (Appearance > Themes)
2. Check version is 3.1.0 (should show in theme details)
3. Clear browser cache (Ctrl+Shift+R)
4. Try different browser

### "Templates won't import"
**Note:** Template import is currently a placeholder (shows progress but doesn't import content yet). Full import functionality coming in v3.2.0.

**Workaround:** Use WordPress Customizer to manually set up pages.

### "Advanced settings are locked"
**Expected:** Advanced settings require Pro tier or higher.

**Fix:**
1. Purchase Pro/Advanced/Agency license
2. Go to Nexus > License
3. Enter license key
4. Click Activate
5. Return to Settings - now unlocked!

### "Dashboard looks unstyled"
**Fix:**
1. Clear browser cache
2. Check browser console for errors (F12)
3. Verify `/assets/admin/css/admin.css` exists in theme folder
4. Try incognito/private window
