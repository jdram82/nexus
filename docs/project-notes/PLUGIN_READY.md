## 🚀 INSTALL NOW (5 Minutes)

### Step 1: Download the Zip (Already Done! ✅)
The file is at: `/workspaces/codespaces-blank/nexus-theme/ul-nec-compliance.zip`

### Step 2: Upload to WordPress

**Option A: Via WordPress Admin (Recommended)**
```
1. Go to: https://jdsancontrols.com/wp-admin
2. Navigate to: Plugins → Add New
3. Click: "Upload Plugin"
4. Choose: ul-nec-compliance.zip
5. Click: "Install Now"
6. Click: "Activate"
```

**Option B: Via FTP/File Manager**
```
1. Unzip ul-nec-compliance.zip
2. Upload ul-nec-compliance folder to:
   /wp-content/plugins/ul-nec-compliance/
3. Go to: Plugins → Installed Plugins
4. Find: "UL-NEC Compliance AutoCAD Plugin Manager"
5. Click: "Activate"
```

### Step 3: Configure Supabase Credentials (2 Minutes)

**Option A: wp-config.php (Most Secure - Recommended)**

Add these lines to `wp-config.php` BEFORE `/* That's all, stop editing! */`:

```php
// UL-NEC Supabase Configuration
define('ULNEC_SUPABASE_URL', 'https://YOUR-PROJECT.supabase.co');
define('ULNEC_SUPABASE_ANON_KEY', 'your-anon-key-from-supabase');
define('ULNEC_SUPABASE_SERVICE_KEY', 'your-service-role-key-from-supabase');
```

**Option B: Admin Settings (Easier)**

```
1. Go to: UL-NEC → Settings
2. Enter Supabase URL
3. Enter Supabase Anon Key
4. Enter Supabase Service Key
5. Click: "Save Settings"
```

### Step 4: Test Connection (1 Minute)

```
1. Go to: UL-NEC → Dashboard
2. You should see: "✅ Supabase Connected"
3. If not: Double-check your credentials
```

## 🆘 TROUBLESHOOTING

### "Plugin won't activate"
- Check PHP version ≥ 7.4
- Check WordPress version ≥ 5.8
- Review error logs

### "Supabase Connection Failed"
- Verify URL has no trailing slash
- Check anon key is correct
- Check service key is correct
- Test in Supabase dashboard first

### "Can't see admin menu"
- Make sure you're logged in as admin
- Clear browser cache
- Check plugin is activated
