### Desktop (> 1280px)
- 4-column stat cards
- 4-column template grid

- Stacked sidebars

### Mobile (< 782px)
- 1-column stat cards
- 2-column template grid
- Full-width elements
- Vertical navigation
- Touch-optimized buttons

## ✨ UI States

### License Tiers

**Free Tier:**
- Stats show: License: Free, Templates: 4, Features: 4
- Premium templates show 🔒 locked badge
- Advanced settings show locked state
- Upgrade cards visible

**Pro Tier ($99/year):**
- Stats show: License: Pro, Templates: 8, Features: 8+
- All templates unlocked
- Advanced settings accessible
- No upgrade cards

**Advanced Tier ($149/year):**
- Stats show: License: Advanced, Templates: 8, Features: 12+
- All templates unlocked
- All settings accessible
- Theme Builder, A/B Testing, Analytics unlocked

**Agency Tier ($399/year):**
- Stats show: License: Agency, Templates: 8, Features: 15+
- Everything unlocked
- White-Label, Cloud Storage, Payment Gateway

## 🎯 User Flows

### First-Time User (Free Tier)
```
1. Install Nexus Theme
2. See Dashboard with Free license
3. Browse Templates → See 4 free + 4 locked
4. Import "Business Hub" template
5. Go to Settings → See advanced section locked
6. See upgrade prompt → Purchase Advanced
7. Activate license
8. Return to Dashboard → See all features unlocked
```

### Existing User (Upgrading)
```
1. Already using Nexus Free
2. Purchase Advanced license
3. Receive email with key
4. Go to Nexus > License
5. Enter key and activate
6. Return to Nexus > Dashboard
7. See stats updated to Advanced
8. Browse Templates → All 8 now unlocked
9. Settings → Advanced section now accessible
10. Import premium template
```

## 🎨 Design Principles

1. **Clean & Modern** - Minimalist card-based design
2. **Visual Hierarchy** - Important info stands out
3. **Consistent Spacing** - 20px grid system
4. **Color Psychology** - Purple = premium, Green = success
5. **Accessibility** - High contrast, readable fonts
6. **Responsive** - Mobile-first approach
7. **Progressive Disclosure** - Show what's needed, hide complexity
8. **Feedback** - Always confirm user actions
