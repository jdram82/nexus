# Theme Screenshot Instructions

## Add Your Theme Thumbnail

To display a thumbnail for the Nexus theme in WordPress, you need to add a screenshot file.

### Quick Steps:

1. **Create or find an image:**
   - Dimensions: **1200 x 900 pixels** (recommended)
   - Format: **PNG** (required)
   - Content: Your website design, logo, or branded image

2. **Name the file:**
   - Must be named: `screenshot.png`

3. **Upload location:**
   ```
   /wp-content/themes/nexus-theme/screenshot.png
   ```

4. **Upload via:**
   - **EasyWP File Manager**
   - **FTP Client** (if available)
   - **WordPress File Manager Plugin**

### Using EasyWP File Manager:

1. Login to **EasyWP Dashboard**
2. Go to **File Manager**
3. Navigate to: `public_html/wp-content/themes/nexus-theme/`
4. Click **Upload**
5. Select your `screenshot.png` file
6. Refresh **Appearance → Themes** in WordPress to see it!

### Creating a Screenshot:

**Option 1: Take a Screenshot of Your Site**
1. After customizing your theme, open your site
2. Take a full-page screenshot (browser extensions available)
3. Crop to 1200x900px
4. Save as `screenshot.png`

**Option 2: Design in Canva (Free)**
1. Go to Canva.com
2. Create custom size: 1200 x 900 px
3. Design your theme preview
4. Download as PNG
5. Rename to `screenshot.png`

**Option 3: Use Photoshop/Figma**
1. Create new document: 1200 x 900 px
2. Design your preview
3. Export as PNG
4. Name it `screenshot.png`

### What Makes a Good Screenshot?

✅ Shows your branding/logo  
✅ Displays main colors  
✅ Clean and professional  
✅ Represents your site design  
✅ Easy to recognize at small size  

❌ Avoid lorem ipsum text  
❌ Don't use stock photos unrelated to your brand  
❌ Keep it simple and clear  

### File Size:

- Keep under 1MB for faster loading
- WordPress will automatically resize for display
- PNG format maintains quality

---

After uploading, the theme thumbnail will appear in:
- **Appearance → Themes** (WordPress admin)
- Theme details page
- Theme customizer preview

**No screenshot = default checkered pattern** (like you see now)
