## 📍 Where to Find Templates

### Option 1: Dashboard (Visual Browse)
```
WordPress Admin → Nexus → Templates
```
- **Purpose:** Browse template designs visually
- **Features:** Category filters, preview images, Pro badges
- **Use for:** Design inspiration

### Option 2: Block Patterns (Build Pages)
```
Page Editor → + Button → Patterns → "Nexus Starter Templates"
```
- **Purpose:** Actually build pages
- **Features:** 5 ready-to-use sections
- **Use for:** Creating content NOW
