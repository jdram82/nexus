## 🚀 Quick Start

### Installation (3 Minutes)

```bash
# Option 1: Git Clone
cd wp-content/themes/
git clone https://github.com/jdram82/nexus.git nexus-theme

# Option 2: Download ZIP
# Download from GitHub, extract to wp-content/themes/
```

### Activation

1. Go to **WordPress Admin → Appearance → Themes**
2. Find "Nexus" and click **Activate**
3. Navigate to **Nexus Pro → Dashboard**
4. Click **"Run Database Setup"** (first-time only)
5. Start building! 🎉

### 🔄 Automatic Updates (NEW)

Nexus now includes automatic GitHub-based updates:

1. **No manual reinstallation** - Updates happen with one click
2. **Update notifications** - Get notified when new versions are available
3. **Settings preserved** - All your configurations stay intact
4. **One-click update** - Go to Appearance → Themes and click "Update Now"

See [Update Guide](docs/THEME_UPDATE_GUIDE.md) for details.

- ✅ WordPress 6.0+
- ✅ PHP 7.4+
- ✅ MySQL 5.7+
- ✅ WooCommerce 5.0+ (optional, for e-commerce)
- ✅ Modern browser (Chrome, Firefox, Safari, Edge)

### Hooks & Filters

**Custom Actions:**
```php
// Before builder canvas
do_action('nexus_before_builder_canvas');

// After widget render
do_action('nexus_after_widget_render', $widget);

// Portal dashboard content
do_action('nexus_portal_dashboard');

// Analytics tracking
do_action('nexus_track_pageview', $page_id);
```

**Custom Filters:**
```php
// Modify builder widgets
apply_filters('nexus_builder_widgets', $widgets);

// Customize analytics metrics
apply_filters('nexus_analytics_metrics', $metrics);

// Modify SEO schema
apply_filters('nexus_seo_schema', $schema);

// Performance recommendations
apply_filters('nexus_performance_recommendations', $recommendations);
```

### Creating Custom Widgets

```php
// Add to functions.php or custom plugin

add_filter('nexus_builder_widgets', function($widgets) {
    $widgets['testimonial-slider'] = array(
        'type'     => 'testimonial-slider',
        'title'    => __('Testimonial Slider', 'my-theme'),
        'icon'     => 'dashicons-format-quote',
        'category' => 'custom',
    );
    return $widgets;
});

// Render your widget
add_action('nexus_render_widget_testimonial-slider', function($widget) {
    ?>
    <div class="testimonial-slider">
        <div class="testimonial-content">
            <?php echo wp_kses_post($widget['content']); ?>
        </div>
    </div>
    <?php
});
```
